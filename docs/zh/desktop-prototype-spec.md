# pentimento 桌面端原型规范

> 状态：**P-005 产物，待原型绘制与审核**。本规范基于 `DESIGN.md` 的 Operate 模式、`docs/zh/requirements.md` R01–R19、Qt Widgets 桌面约定，以及 ui-ux-pro-max 关于键盘导航、焦点、空状态、加载与错误反馈的检索结果形成；不采用营销页 Hero/CTA/响应式落地页结构。

## 1. 信息架构与桌面布局

### 1.1 主窗口

- 最小窗口 `860×540`；默认 `1240×790`；三栏为可选、可记忆的 `QSplitter`。
- 主工具栏：`导入`、`记录版本`、`编辑工作副本`、`打开素材库`；菜单承载素材库、连接、备份、设置、帮助。
- 左栏 `素材`：层级/文件夹树、名称搜索、组合筛选、视图切换（网格/列表）、排序、资产列表、批量导入入口。
- 中栏 `预览`：技术元数据、可缩放大图、透明/棋盘底切换、版本对比入口、缩放与同步缩放控件。
- 右栏 `版本时间轴`：最新在前，含当前态、历史态、已缓存、缺失、锁定、只读、损坏等状态；下方为对比、导出、恢复等操作。
- 状态栏：素材库路径、选择/可见数量、连接/离线状态、后台任务进度、最后错误及重试。

### 1.2 尺寸与折叠

- 面板默认宽度：左 `260px`、中 `660px`、右 `300px`；左/右最小 `200px`，预览最小 `240×200`。
- 窗口小于 `1000px` 时右栏优先折叠为摘要按钮；小于 `860px` 不再支持。左栏在窗口小于 `920px` 时可由用户折叠。
- 面板可整窗隐藏；再次打开后恢复用户上次宽度、滚动位置、选择与焦点。

### 1.3 主要模式/页面

- **资产浏览**：默认模式，左/中/右联动。
- **版本对比**：并排/滑动/同步缩放；从时间轴任选两个版本进入，`Esc` 返回浏览模式并保留选择。
- **整库时间点**：按快照时间浏览历史目录树、已删除资源与缺失项；操作只读预览。
- **恢复预演**：按资源列出新增/覆盖/跳过/冲突，必须确认保护当前状态后才能继续。
- **NAS/仓库连接**：左侧独立根节点或工具栏连接面板，覆盖发现、手动地址、认证、能力与离线状态。
- **任务中心**：非模态进度列表，含取消与结果清单；不阻塞浏览。

### 1.4 视觉与平台约定

- 遵循 Qt Widgets 原生控件、系统主题、系统字体、原生焦点框与菜单快捷键；禁止 WebView 营销风格。
- 预览画布固定中性 `#E5E5E2` / 文字 `#444845`，透明底为棋盘格；其余颜色交由平台主题与语义色处理。
- 图标使用一套平台自绘 SVG/图标库，同层级一致；有可见文本时图标为装饰，独立图标按钮必须带 tooltip 与 accessible name。
- 状态表达不能只靠颜色：图标/文本标签必须同时存在；焦点与选中态始终可见。

## 2. 桌面状态规范

### 2.1 主窗口状态

| 状态 | 触发 | UI 表现 | 允许操作 |
|---|---|---|---|
| No library | 未打开/新建库 | 空状态展示创建、打开、最近库；最近项显示可达/不可达 | 创建、打开、定位失效路径、设置、帮助 |
| Library opening | 打开/新建 | 局部进度 + 禁用资产操作 | 取消 |
| Library invalid/locked/unreachable | 校验失败 | 明确错误、原因、恢复建议；最近项标注 | 重试、打开其他库、定位新路径、帮助 |
| Ready | 索引完成 | 展示资产、状态栏路径 | 全部浏览/导入/编辑/版本操作 |
| Indexing/importing | 后台任务 | 任务中心进度、取消、结果清单 | 取消、继续浏览已载入资产 |

### 2.2 资产与预览状态

| 状态 | 触发 | UI 表现 | 允许操作 |
|---|---|---|---|
| Empty library | 无资产 | 说明 + `导入` 主操作，不留白 | 导入、打开库目录 |
| Empty result | 搜索/筛选无结果 | 显示条件摘要与 `清除筛选` | 清除条件、调整搜索 |
| Loading assets | 查询中 | 局部进度/骨架，不清空选择 | 取消、继续其他面板 |
| Selected-image | 选中可预览图像 | 大图、尺寸/格式/大小、缩放控件 | 缩放、透明底、编辑、记录、历史 |
| No-preview format | 无图像解码 | 明确“原文件保留，暂无预览”，显示字节/格式信息 | 打开/导出/历史，不禁用资产 |
| Remote uncached | 远端未下载 | “未缓存”原因、体积与所需操作 | 按需下载（需确认）、跳过 |
| Downloading | 按需读取 | 进度、取消、失败重试 | 取消 |
| Offline/failed source | 源不可达/失联 | 源路径、失败原因、重连/重试 | 本地缓存浏览、重连、查看错误 |
| Missing/deleted | 删除墓碑或对象缺失 | 明确缺失类型与影响范围 | 从历史恢复（若对象可得）、定位、帮助 |
| Corrupted object | 哈希校验失败 | 阻断恢复/导出，展示对象与校验错误 | 一致性检查、复制诊断信息、帮助 |

### 2.3 版本状态

| 状态 | 触发 | UI 表现 | 允许操作 |
|---|---|---|---|
| Current | 最新工作内容 | 顶部“当前”标签，未保存变化提示 | 编辑、记录、对比、导出 |
| History normal | 已选中历史 | 缩略图、本地时间、说明、体积、对象校验态 | 预览、对比、导出；只读后端不显示恢复 |
| Pinned/key | 关键版本 | 图标+文本，不被自动策略预演选中 | 查看固定原因、取消固定（若有权限） |
| Cached | 已缓存历史对象 | 可直接预览 | 全部只读操作 |
| Missing remote | Git LFS/SVN 等远端对象缺失 | 显示后端、缺失原因、获取成本 | 明确同意后按需获取；拒绝保持缺失 |
| Locked | SVN 锁等 | 锁信息（可得时） | 只读浏览，不覆盖锁 |
| Read-only backend | Git/SVN/时光机 | 明确“只读”，隐藏直接写回恢复按钮 | 提取/导出到库外 |
| Recovery preview | 恢复前 | 新增/覆盖/跳过/冲突分类、目标列表 | 修改选择、查看影响、确认/取消 |
| Recovering | 恢复中 | 进度、不可关闭对话框/任务进度 | 取消（仅安全阶段） |
| Recovery failed/interrupted | 失败/中断 | 明确完成、失败或需重启收敛；不得隐藏半恢复 | 查看日志、重试、支持动作 |

### 2.3.1 R06 快照策略与排除规则状态

| 状态 | 触发 | UI 表现 | 允许操作 |
|---|---|---|---|
| Snapshot scheduling | 定时快照已启用 | 设置页/快照面板显示启用开关、周期与下次时间 | 启用/暂停、调整周期、立即快照、查看策略 |
| Snapshot paused | 用户或系统暂停 | 醒目“已暂停”，显示暂停原因与已停用时点 | 恢复、手动立即快照、查看策略 |
| Snapshot running | 快照进行中 | 进度、当前对象、可取消性 | 取消（仅安全阶段）、查看日志 |
| Snapshot failed | 快照失败 | 明确失败原因、影响范围、恢复建议 | 重试、查看日志、帮助 |
| Exclusion rules | 规则集生效中 | 规则列表（路径/模式/扩展名）、命中计数、启停 | 增删改规则、查看命中、临时忽略 |
| Exclusion hit | 候选被排除 | 排除原因、所属规则、可选“加入忽略名单” | 查看、编辑规则、手动纳入 |

### 2.3.2 R07 元数据历史状态

| 状态 | 触发 | UI 表现 | 允许操作 |
|---|---|---|---|
| Metadata history available | 存在元数据版本 | 分字段列出旧名称/标签/评分/备注/来源，标注变更时间与操作者 | 逐字段回看、对比、导出、恢复 |
| Metadata field changed | 字段有变更 | 高亮变更字段，显示旧值→新值与变更说明 | 回看历史、接受/回退该字段 |
| Metadata history empty | 无元数据历史 | 说明“元数据自当前版本起记录”，不臆造历史 | 记录当前、设置 |
| Metadata history conflict | 同字段多值冲突 | 列出候选值与来源，需选择 | 选择候选、保留当前、合并 |

### 2.4 后台任务与错误

- 短等待 `100–300ms` 内不闪现加载；长任务必须有进度、当前项、可取消性；不可取消需说明原因。
- 对话框错误需含标题、具体原因、恢复动作；状态栏错误保留入口，消失前不得自动关闭。
- 网络断线只切换连接状态，不清空本地缓存列表；重连后核对远端删除/改名，不冒充本地删除。
- 备份、清理、一致性检查一律先预演并列依据，不立即写/删。

### 2.5 空状态文案原则

- 说明现状、给出下一步动作；禁止裸空白。
- 不夸大能力：无法解析的 PSD/模型明确“原文件保留，暂无合成预览”。
- 缺失与不支持分开；认证失败、权限不足、离线、TLS/SSH 校验失败分别显示。

## 3. 键盘交互规范

### 3.1 全局与导航

| 按键/组合 | 行为 |
|---|---|
| `Ctrl+O` | 导入资产 |
| `Ctrl+S` | 记录当前资产版本 |
| `Ctrl+F` | 聚焦名称搜索 |
| `Ctrl+Shift+F` | 打开组合筛选面板 |
| `F6` | 循环焦点：左栏 → 中栏 → 右栏 → 状态/工具栏 |
| `Alt+Left/Right` | 面板焦点左右移动 |
| `Tab / Shift+Tab` | 面板内按视觉顺序遍历可操作控件 |
| `Ctrl+1/2/3` | 聚焦资产/预览/时间轴面板 |
| `Ctrl+B` | 显示/隐藏左栏 |
| `Ctrl+Shift+H` | 显示/隐藏右栏 |
| `Ctrl+K` | 打开命令/快速跳转（资产、版本、连接、命令） |
| `Esc` | 关闭浮层/取消当前编辑/退出对比；不无提示关闭应用 |

### 3.2 资产浏览

| 按键/组合 | 行为 |
|---|---|
| `↑/↓` | 列表模式移动选择并保持滚动可见 |
| `←/→` | 网格模式水平移动；列表模式折叠/展开层级（无层级时移动到相邻资产） |
| `↑/↓` | 网格模式垂直移动 |
| `Home/End` | 首项/末项 |
| `PgUp/PgDn` | 翻页并保持选择可见 |
| `Ctrl+A` | 选择当前过滤结果全部资产 |
| `Space` | 保留选择并切换当前项勾选状态（用于批量操作） |
| `Ctrl+G / Ctrl+Shift+G` | 网格/列表切换 |
| `Enter` | 打开当前资产详情/预览；仅在明确上下文打开工作副本 |
| `Delete` | 仅显示删除预演；不直接删除 |
| `Shift+F10 / Menu` | 打开上下文菜单 |

### 3.3 预览与缩放

| 按键/组合 | 行为 |
|---|---|
| `+ / =` | 放大 |
| `-` | 缩小 |
| `0` | 适配窗口 |
| `1` | 100% |
| `Arrow keys` | 平移（当图像大于视口时） |
| `Ctrl+Arrow` | 平移加速 |
| `T` | 切换透明/棋盘底 |
| `Ctrl+Shift+C` | 进入版本对比 |

### 3.4 时间轴与对比

| 按键/组合 | 行为 |
|---|---|
| `↑/↓` | 新→旧方向按视觉顺序移动版本选择 |
| `Home/End` | 当前/最早版本 |
| `Space` | 将另一对比槽设为当前版本 |
| `Tab` | 对比槽 A/B 切换 |
| `←/→` | 滑动对比模式下移动分界线；并排模式下小幅平移 |
| `[ / ]` | 调整分界线步进 |
| `Ctrl+=` | 同步放大两侧 |
| `Ctrl+-` | 同步缩小两侧 |
| `Ctrl+0` | 同步适配 |
| `Enter` | 只读后端提取/导出；可写后端打开恢复预演 |
| `Esc` | 退出对比并返回浏览模式 |

### 3.5 对话框、恢复与危险操作

| 按键/组合 | 行为 |
|---|---|
| `Tab / Shift+Tab` | 仅在当前对话框内循环；打开时移入首个控件，关闭后还原原焦点 |
| `Enter` | 激活默认按钮；仅当默认按钮明确安全时设为默认 |
| `Esc` | 取消/关闭；不可取消任务改为解释原因 |
| `Ctrl+R` | 在恢复预演中刷新影响 |
| `Ctrl+Enter` | 确认恢复；必须先经过保护当前状态与结果确认 |
| `Shift+Tab` | 反向遍历（属上行对话框内循环的反向路径）：确认按钮 → 摘要列表，支持复核 |
| `Alt+underlined letter` | 平台菜单/按钮助记键 |

### 3.6 可访问性与焦点规则

- 所有可操作控件必须可键盘到达，焦点框不可移除；无键盘陷阱（模态对话框除外，且 `Esc`/关闭按钮可达）。
- Tab 顺序等于视觉顺序；面板内导航优先，`F6/Ctrl+1/2/3` 提供跨面板跳转，减少无效遍历。
- 列表/网格键盘选择变化必须滚动可见；多选状态与勾选状态分别暴露。
- 独立图标按钮、状态图标、缩略图必须有 accessible name；状态不能只靠颜色或位置。
- 搜索/筛选改变结果时，保留当前选择；当前项被过滤后焦点移到相邻可见项，不落到无操作区域。
- 快捷键在菜单或快捷键帮助中可见；平台冲突时优先系统保留快捷键。

## 4. 原型验收清单

- [ ] 主窗口、浏览、对比、时间点、恢复预演、连接、任务中心均有布局与状态图。
- [ ] 每个状态包含触发、表现、允许操作、错误恢复。
- [ ] 关键流程（导入、浏览、筛选、编辑、记录、对比、恢复、连接、离线）可仅用键盘完成。
- [ ] 只读后端不出现直接恢复按钮；缺失/缓存/损坏/锁定/只读可区分。
- [ ] 无营销页 Hero/CTA/响应式落地页结构；保持桌面三栏 Operate 模式。
- [ ] 焦点、选中、禁用、加载、错误、进度、取消状态全部可见。
