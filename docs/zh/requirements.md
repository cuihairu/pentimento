# V1 需求范围（草案，待确认）

> 状态：**草案，未拍板**。本文由 todo P-001 起草，供逐项确认 R01–R19 纳入/排除。`[建议]` 为起草方倾向，非用户决定；`[决策点]` 需用户拍板。

## R01 素材库创建与打开

- 说明：创建/打开本地素材库；无效、锁定、不可达目录返回明确错误；最近列表与失效路径重新定位（P-201、P-202）。
- [建议] **纳入**。核心基础，无依赖前置。
- [决策点] 是否允许库路径本身位于可移动卷（U 盘/外置盘），以决定“重新定位”是否必须支持跨卷。

## R02 素材导入

- 说明：管理式复制导入；外部目录索引；递归目录导入与忽略规则；导入取消与结果清单（P-203–P-206）。
- [建议] **纳入**复制导入与递归/忽略/取消。**暂缓**外部目录索引（P-204）——它不复制、不改来源，涉及持续追踪与源变化语义，需单独评估。
- [决策点] 外部目录索引是否纳入 V1？若纳入，来源文件移动/删除时库内身份如何处理。

## R03 素材浏览

- 说明：网格/列表两种视图，保持选择、排序、滚动定位；图片缩放与透明底；名称搜索与组合筛选（P-208、P-209、P-217）。
- [建议] **纳入**。桌面三栏布局与 Eagle 式浏览习惯一致。
- [决策点] 组合筛选是否包含“格式 + 尺寸 + 标签 + 评分 + 名称”全部条件，还是 V1 仅名称 + 标签。

## R04 图像格式与降级

- 说明：PNG/JPEG/WebP/TGA/BMP 验证样本；不支持格式可见；PSD 合成预览评估；技术元数据提取（P-210–P-212）。
- [建议] **纳入**首批格式与元数据（格式、尺寸、大小、可读色彩/通道）。**PSD 合成预览仅评估、不强做**——若无法可靠解析则保留原文件字节。
- [决策点] PSD 是否必须产出合成预览图，还是“支持原始字节预览 + 明确不可预览”即可满足 V1。

## R05 素材元数据

- 说明：标签维护；评分与备注；来源/作者/授权记录；文件夹组织与资源身份；搜索组合（P-213–P-217）。
- [建议] **纳入**标签、评分、备注、来源授权。**文件夹组织（P-216）需权衡**——当前工作副本路径为绝对路径，库内移动/改名会影响路径语义。
- [决策点] 库内文件夹组织（改名/移动后历史归属保持）是否纳入 V1，还是延后到路径相对化改造之后。

## R06 自建版本管理

- 说明：内容对象存储（流式哈希/去重/校验）；手动记录；稳定变化自动记录；定时快照与暂停；排除规则；关键版本固定（P-301–P-307）。
- [建议] **纳入**对象存储、手动记录、自动记录（启发式）、关键版本固定。**定时快照与排除规则**建议 V1 保留，但快照策略需与整库时间点（R08）一起确认。
- [决策点] 自动记录的“稳定判断”是否接受当前启发式（大小+mtime 连续两次 2 秒稳定），还是 V1 就引入文件监视器/编辑器感知。

## R07 时间轴浏览

- 说明：单素材时间轴；元数据历史（P-308、P-309）。
- [建议] **纳入**单素材时间轴。**元数据历史**建议纳入（V1 保留旧名称/标签/备注/来源），数据量小、价值高。
- [决策点] 元数据历史是否必须逐字段可回看，还是仅保留最新值即可。

## R08 整库时间点

- 说明：删除墓碑；整库一致快照；时间点目录浏览（P-310–P-312）。
- [建议] **纳入**删除墓碑与整库一致快照。**整库时间点回溯**是“时光机”核心体验，但依赖 R06 快照策略；建议 V1 纳入，但实现难度高于单文件历史。
- [决策点] 整库一致快照是否必须成为 V1 交付边界，还是 V1 仅完成单素材历史 + 删除墓碑。

## R09 版本对比

- 说明：并排与同步缩放；滑动对比（P-313、P-314）。
- [建议] **纳入**并排与同步缩放；**滑动对比纳入**（同坐标区域检查）。
- [决策点] 对比是否仅限图像素材，还是也支持文本/源文件以文本 diff 呈现。

## R10 恢复

- 说明：恢复预演；恢复前保护当前状态；单素材恢复为新版本；快照内选中项恢复（P-315–P-318）。
- [建议] **纳入**。恢复是核心价值，预演与保护当前状态是安全前提。
- [决策点] 快照内选中项恢复（P-318）是否 V1 交付，还是 V1 仅单素材恢复。

## R11 历史导出与恢复日志

- 说明：历史副本导出；恢复日志与重启收敛（P-319、P-320）。
- [建议] **纳入**导出。**恢复日志/重启收敛**建议纳入——它解决当前“进程断电不构成跨 SQLite/文件系统原子事务”的已知缺口。
- [决策点] 恢复日志机制是否要求在 V1 完成，还是作为 V2 已知限制记录。

## R12 Git 后端

- 说明：识别并连接本地 Git 仓库；读取文件树/日志；提取历史文件；识别 LFS 指针与缺失对象；LFS 明确同意后按需获取（P-401–P-405）。
- [建议] **纳入为只读适配**。展示仓库/分支/提交/工作区状态，不修改仓库；提取到临时/导出位置。LFS 按需获取仅在用户明确同意后执行。
- [决策点] Git 后端是否为 V1 必备，还是“可延后到 V1.x 的能力扩展”。

## R13 SVN 后端

- 说明：连接 SVN 工作副本或 URL；读取日志树与锁信息；提取历史文件（P-406–P-408）。
- [建议] **纳入为只读适配**，认证失败与只读权限分别显示；不提交、不更新覆盖。
- [决策点] 与 R12 同步：SVN 是否作为 V1 必备后端，或仅 Git + 自建即可。

## R14 后端能力统一与时光机

- 说明：统一后端历史能力显示；定义 macOS 时光机系统集成边界；实现能力提示与系统入口（P-409–P-411）。
- [建议] **纳入**。只读后端不显示可直接写回的恢复按钮；时光机仅 macOS 提供系统入口，不解析备份格式。
- [决策点] 时光机是否只做“系统入口跳转 + 能力提示”，还是需要读取 Time Machine 快照内容（后者超出当前 V1 边界）。

## R15 NAS 挂载来源

- 说明：支持系统挂载 SMB/NFS 来源；可索引已挂载共享；识别失联与只读权限（P-501）。
- [建议] **纳入**（仅索引已挂载目录，不自行挂载/认证）。
- [决策点] 是否要求应用自行触发系统挂载（如 `mount_smbfs`/`mount`），还是仅消费用户已挂载的目录。

## R16 WebDAV/SFTP 直接访问

- 说明：HTTPS WebDAV 列目录与按需读取；SFTP 列目录与按需读取（P-502–P-505）。
- [建议] **纳入**直接 WebDAV/SFTP 只读访问，按需读取可取消，不默认写回。
- [决策点] WebDAV/SFTP 是否必须在 V1 实现，还是仅“挂载 SMB/NFS”即满足 V1 NAS 需求。

## R17 服务发现

- 说明：mDNS/DNS-SD；WS-Discovery；发现结果合并与过期（P-506–P-508）。
- [建议] **纳入**mDNS/DNS-SD；**WS-Discovery 建议纳入**（Windows 生态常见）；结果合并保留多地址/协议。
- [决策点] 若 V1 仅支持挂载来源（R15），发现机制是否也延后，或仍纳入作为便捷入口。

## R18 手动连接与安全

- 说明：手动添加地址（主机名/IPv4/IPv6/端口/协议）；共享选择与能力探测；TLS 证书校验；SSH 主机密钥校验；断线重连状态机；离线缓存浏览；重连后目录变化核对（P-509–P-515）。
- [建议] **纳入**（若 R16/R17 纳入）。证书/密钥校验必须严格：无效证书阻止自动连接，新主机需确认，已知密钥变化需明确处理。
- [决策点] 离线缓存浏览（P-514）是否 V1 交付，还是仅在线浏览 + 明确“未缓存”提示。

## R19 备份与可靠性

- 说明：NAS 备份包导出与校验；对象/索引一致性检查；空间与保留策略预演；可恢复备份校验流程（P-516、P-601–P-603）。
- [建议] **纳入**一致性检查、保留策略预演（不立即删除）、备份校验流程。**NAS 备份包导出（P-516）**若 R16 纳入则一并纳入。
- [决策点] 保留策略在 V1 是“仅预演/不删除”还是允许实际清理（后者与“无历史删除/GC”核心约定冲突，需用户明确）。
