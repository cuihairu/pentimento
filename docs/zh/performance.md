## 建议阈值

| 指标 | 建议阈值 | 备注 |
|---|---|---|
| 首次导入吞吐 | ≥ 100 MiB/s | 本地 NVMe，排除源目录扫描以外的网络因素 |
| 缩略图生成 | 512 张/分钟 | 512 KiB PNG/JPEG/WebP |
| 名称搜索 | P95 < 200 ms | 2,000+ 资源 |
| 组合筛选 | P95 < 500 ms | 名称+标签+格式+尺寸 |
| 时间轴打开 | < 500 ms | 单素材 100 版本 |
| 整库快照 | < 10 s | 2,000 资源，内容未变化 |
| 恢复 64 MiB 文件 | < 3 s | 含哈希校验 |

## 可验证口径

- 吞吐以对象写入字节数/耗时计算，排除 UI 线程阻塞影响。
- 缩略图以完整生成完成为准，不含队列等待时间。
- 搜索/筛选以 SQLite 查询完成时间为准，不含界面渲染。
- 快照/恢复以核心库 API 返回时间为准，不包含对话框交互。

## 决策点

- D-20：样本总规模 30 GiB 是否可接受，是否需要降到 10 GiB/5 GiB 快速档。
- D-21：目标硬件是否仅按当前 Linux 开发机（NVMe/Qt 6.10）设定。
- D-22：PSD 是否必须产出合成预览，还是仅原字节保留+降级状态。
- D-23：上述阈值是否需要按 Windows/macOS 分别放宽/收紧。
