# 素材库设计与验收（代决执行，2026-10-30）

> 状态：**已代决**。依据 `docs/review/2026-10-30-decisions.md` 执行 P-201–P-217 的立即动作。各节为该任务在当前阶段的验收定义/语义设计/样本矩阵；**实现须待 P-015 批准**，本节不构成实现完成。

## P-201 库创建与打开（六类验收）

| 类别 | 触发 | 验收（返回明确错误/状态） |
|---|---|---|
| 新建 | 新路径 | 建 `catalog.sqlite`+`objects/`+`working/`+`library.lock`，索引就绪 |
| 有效库 | 已有库打开 | 校验库 ID 与 schema 版本；就绪 |
| 无效目录 | 非库/损坏索引 | 明确「库损坏或非有效库」，不静默重建 |
| 已锁定 | 另一进程持锁 | 明确「被占用」，提示关闭他处 |
| 权限不足 | 无写权限 | 明确「权限不足」+ 恢复建议 |
| 拔盘 | 库卷不可达 | 明确「库不可达」，不自动新建空库（防误以为素材消失） |

不做：失败位置静默重建；多进程同时写（QLockFile 单写者）。

## P-202 最近素材库与重新定位（库身份与相对路径）

- 库身份：稳定库 ID（首次创建生成，持久化），不随路径变化。
- 相对路径：资源/对象路径相对库根；库根变更后相对路径不变，历史不断链。
- 跨卷重定位：支持库目录整体搬移到可移动卷/新盘；仅替换路径文本会打开同名错误库或破坏对象引用，故须校验库 ID。
- 迁移失败处理：目标不可写/空间不足/校验失败 → 明确错误，不修改原库。
- **验证**：用库副本（非原库）做搬移实验；不自动扫描所有磁盘猜库位置。

## P-203 复制导入（顺序与失败清理）

顺序：稳定读取来源（不边读边变） → 临时写入工作副本（`working/<uuid>/` 原子写） → 完整校验（哈希） → 登记索引（资源+第一版） → 原文件不变。失败清理：登记前失败删除临时文件；登记后失败标记未完成，重试可续。来源复制时变化/磁盘满 → 明确错误，不产生不完整导入。不做：移动/删除原件；去重≠合并不同素材身份（同内容共享对象，不同导入仍独立素材）。

## P-204 外部目录索引（延后，重启条件）

延后为独立专题。**重启条件**（满足后另行排期）：真实项目样本；用户必须原地编辑（库内复制不可满足）；身份映射（路径↔资源 ID）与删除/改名语义获批。**明确**：不以 NAS 导入功能冒充外部索引；不自动改写源目录。

## P-205 递归目录导入与忽略规则

- 递归：默认**不跟随目录符号链接**（防循环）；隐藏目录按规则显式处理。
- 忽略规则：路径/模式/扩展名，可预览（导入前显示命中）。
- 展示：候选数、排除原因（每条）、权限失败项（不静默吞掉不可读子目录，列出并允许跳过/重试）。
- 边界：不默默越过来源根目录；默认列出将导入内容与排除清单再确认。

## P-206 导入取消与结果清单

- 取消按文件边界生效：当前文件收尾（完成或丢弃该文件），已开始文件不留下半写登记。
- 已完成项保留策略：已成功登记的对象/索引保留，不因取消删除（删除会损坏共享内容引用）。
- 结果清单：成功/失败/未处理可区分，重试只处理未完成项。
- 验证：取消后重新打开库，清单与状态一致，无悬挂临时文件（未完成项可清理）。

## P-207 缩略图缓存

- 缓存键：内容哈希 + 生成参数（尺寸、解码器版本）→ 同内容各版本复用，改名/版本变化不显示错误图（不按文件名缓存）。
- 尺寸与解码器版本：缓存记录解码器版本，升级解码器后失效重建。
- 原子写入：临时文件 → 校验 → 改名；损坏缓存回退：读取失败即删除重建，不伤原件。
- 边界：缩略图不是历史内容；缓存损坏不删除原对象。

## P-208 网格与列表浏览

- 共享模型：同一数据模型 + 查询，视图仅渲染不同；切换不重置全部状态。
- 选择按**稳定资源 ID** 保存（不按行号/文件名——排序/筛选后按行号会选中别的资源）。
- 当前项被筛掉后：焦点移到相邻可见项，不落到无操作区；滚动保持可见。
- 视图切换保持选择、排序、滚动定位。

## P-209 图片缩放与透明底

- 等比例缩放；100% / 适配窗口；透明底棋盘格切换。
- **验证样本**：透明 PNG（检查棋盘/透明区域）、极宽图（横向平移边界）、大图（适配与缩放边界）。
- 统一图像坐标规则；适配窗口**不拉伸**图像（拉伸误导质量判断）。
- 边界：缩放后的显示≠像素被修改；不加入图像编辑功能。

## P-210 首批格式与降级（样本表）

PNG/JPEG/WebP/TGA/BMP 建编码、透明、损坏和像素尺寸边界样本表。**本机事实**：Qt 6.10.2 支持 PNG/JPEG/BMP 预览，**WebP/TGA 无插件**（见 30-foundation#P-102）→ 无插件时显示「暂无预览」，原字节保留。

| 格式 | 编码样本 | 透明 | 损坏 | 像素边界 | 本机可预览 |
|---|---|---|---|---|---|
| PNG | 8/16bit、调色板 | 是 | 截断/坏 CRC | 超大尺寸 | 是 |
| JPEG | 基线/渐进 | 否 | 截断/坏标记 | 大尺寸 | 是 |
| WebP | 有损/无损 | 是 | 截断 | 大尺寸 | 否（需插件） |
| TGA | RLE/非 RLE | 是 | 截断/头损坏 | 大尺寸 | 否（需插件） |
| BMP | 非压缩 | 否 | 截断 | 大尺寸 | 是 |

边界：不只看扩展名宣称支持；不无限分配解码内存（超大尺寸先报边界/上限提示）。

## P-211 PSD 合成预览适配（D-04/D-22 统一）

- 统一结论：**可靠保留原字节 + 清楚降级为硬门槛；合成预览可选（非硬门槛）**。
- 样本矩阵：有合成图 / 无合成图 / 损坏文件分开记录；评估出口：限时评估能否解析合成图，失败降级。
- 降级文案：「原文件已保留，暂无合成预览（PSD 解析未支持/失败）」；不称「支持 PSD」代替具体编码/样本范围。
- 不做：图层编辑；部分 PSD 可显示 ≠ 全部支持（错误合成图会误导对比）。

## P-212 技术元数据

- 字段：格式、尺寸、大小、可读色彩/通道；单位与读取来源逐字段记录。
- 未知值明确为空/未知，不编造、不填零；不自动推断作者/授权/内容语义。
- 失败状态：读取失败与「无此字段」分开；验证不支持格式的展示（降级态显示可读信息）。

## P-213 标签维护

- 单个与批量；批量明确「添加」与「移除」，不默认「替换全部标签」（会抹掉不同素材特有标签）。
- 空白处理（忽略空白/去重）；批量预演（影响数量）；结果可查询。
- 标签变更接入元数据历史（P-309）。
- 不做：自动打 AI 标签。

## P-214 评分与备注

- 评分范围（建议 0–5 星，含「无评分」状态）；无评分 ≠ 0 分，独立表示。
- 备注保存时机：失焦/显式保存（明确「已保存」反馈，不让人以为内容已保留）；自动保存时机不清 → 明确说明。
- 持久化 + 重开验证；与元数据版本一起设计（P-309）。
- 不做：评论协作、社交排名、长篇富文本编辑器。

## P-215 来源/作者/授权记录

- 字段：来源、作者、授权；允许未知；记录用户输入时间与来源（人工记录）。
- 附件：授权证据文件引用保存（库内），纳入备份边界。
- 边界：网址/文件存在 ≠ 获得授权，应用不替用户断言许可；不联网抓取/传播素材。
- 验证：旧记录可回看（含来源记录时间）。

## P-216 文件夹组织与资源身份

- 先稳定 ID + 相对路径（P-202），再做库内改名/移动。
- 重名冲突：同文件夹重名须提示，不无提示覆盖；两个资源不同身份不自动合并。
- 跨文件夹移动：更新路径但保持资源 ID，历史属于同一素材。
- 历史路径回看：时间点/元数据历史可见当时路径（P-312）。
- 不做：库外任意移动追踪（用户搬移工作文件不追踪）。

## P-217 名称搜索与组合筛选

- 条件：名称、标签、格式、尺寸、评分，可组合；默认 **AND**；条件摘要可见（不隐藏生效条件）。
- 标签匹配规则：任一标签命中（OR within tag set）；多标签条件 AND。
- 无评分语义：无评分不参与「≥N」过滤；显式「无评分」条件可选。
- 清除：一键清除全部条件；清除后回到全量。
- **补充评分验收**：评分范围与无评分状态（原验收缺，补入）。
- 不做：自然语言/图像语义搜索。
