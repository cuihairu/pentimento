## P-007 版本时间轴原型：四类例子

按代决（R06/R07/R14）：区分当前、历史、损坏、删除；未来远端缓存状态单独标候选（不画成 V1 可用）。

**四类例子**（评审能否准确选择目标版）：

| 例子 | 时间轴呈现 | 选择目标版的可信度 |
|---|---|---|
| 未记录修改 | 顶部「当前」显示「有未保存修改」提示；最新已记录版本为「当前 · <时间>」 | 明确当前工作内容 ≠ 任何已记录版本，防误以为已保存 |
| 正常历史 | 最新在前，缩略图 + 本地时间 + 说明 + 体积 + 对象校验态 | 可直接预览/对比/导出 |
| 删除资源 | 显示墓碑「此素材已删除 · <时间>」；对象可得则可从历史恢复 | 能从时间点找回原身份 |
| 损坏对象 | 缩略图为警告图标 + 「内容损坏/校验失败」；阻断恢复/导出 | 不静默恢复；区分缺失/损坏/不支持 |

**时间排序**：按数据库单调 id 序列排序（非显示时间），本地时间只负责展示；同秒多版本/时区变化/时钟回拨不改变序列（见 50-versioning.md#p-308）。

## P-008 双版本对比原型：对齐与边界

按代决（R09）：图像并排、同步缩放、滑动；不做文本/PSD 图层/三维差异；尺寸不同必须说明对齐方式。

| 情形 | 处理（标注） |
|---|---|
| 等比例 | 两侧同比例缩放，同步原点；重复比较同一局部 |
| 同坐标 | 同步平移，原点一致；分界线两侧同一图像坐标 |
| 尺寸不同 | 默认左上对齐 + 显式说明；不做自动拉伸到同尺寸（避免制造不存在的差异）；提供「适配窗口」统一比例选项 |
| 透明图 | 棋盘底，两侧一致；透明区域不作为「差异」 |
| 一侧不可预览 | 明确「该版本不可预览（损坏/格式不支持）」，对比仍可看另一侧；不静默空白 |

## P-010 恢复预演原型：操作清单与异常状态

按代决（R10/R11）：恢复预演先于任何目标文件写入；影响摘要、逐项冲突、保护当前内容结果是必须项。

**操作清单（新增/覆盖/跳过/冲突）**：

| 类别 | 呈现 | 允许操作 |
|---|---|---|
| 新增 | 目标不存在，将创建 | 勾选纳入/排除 |
| 覆盖 | 目标存在且内容不同 | 勾选；必须经「保护当前状态」成功才可继续 |
| 跳过 | 目标与恢复内容一致 | 默认跳过（可强制覆盖，需显式确认） |
| 冲突 | 目标存在但为不同素材/权限不可写 | 列出冲突，禁止静默解决；需人工选择 |

**异常状态**：

| 状态 | 呈现 | 处理 |
|---|---|---|
| 保护失败 | 当前未记录内容无法保存（磁盘满/权限） | 停止恢复；不允许无保护覆盖；不宣称保存了编辑器未写盘内容 |
| 磁盘不足 | 空间预演不足 | 列出缺口，禁止继续；提示清理/换目标 |
| 取消 | 用户取消 | 未写入文件前可整体取消；已写入部分按日志标记，可重启收敛（P-320） |
| 中断 | 进程中断 | 重开显示「部分恢复，待收敛」，不隐藏半恢复状态 |
| 预演过期 | 预演后文件被编辑 | 执行前重新检查，变化则要求刷新预演 |

**默认安全**：不默认全选覆盖；`Enter` 不设为无提示破坏操作；确认需 `Ctrl+Enter` 且先经保护+结果确认。
