## P-013 第二轮原型交互审核：走查脚本（待用户执行）

按关键任务逐步走查，覆盖错误态与键盘。用户按以下脚本在原型（`docs/zh/desktop-prototype-spec.md` + `docs/zh/design/10-prototype-states.md`）上走查，逐条记录问题与修订：

| 步骤 | 任务 | 必查错误态 | 键盘要求 |
|---|---|---|---|
| 1 | 导入：选择已挂载目录 → 递归导入 → 预览忽略规则 → 中途取消 | 来源不可读、权限不足、磁盘满 | Ctrl+O 起，仅键盘完成；取消有效 |
| 2 | 修改：编辑工作副本 → 等待自动记录 → 手动记录 | 未记录修改提示、编辑器未写盘 | Ctrl+S；焦点不丢失 |
| 3 | 快照：启用定时快照 → 暂停 → 恢复 → 立即快照 | 快照失败、补跑堆积 | 菜单可达；暂停原因可见 |
| 4 | 删除：删除预演 → 确认 → 墓碑 | 拔盘≠删除；不可达资源 | Delete 只显示预演，不直接删 |
| 5 | 预演恢复：选历史版本 → 影响清单 → 保护当前 → 确认 | 保护失败、磁盘不足、中断 | Ctrl+R 刷新；Ctrl+Enter 确认；Esc 取消 |
| 6 | 对比：并排 → 同步缩放 → 滑动 | 尺寸不同、透明图、一侧损坏 | Tab 切槽；←/→ 分界线；Esc 返回 |
| 7 | 失联：拔掉挂载源 → 本地浏览 → 重连 | 挂载 I/O 卡 UI；远端缺失≠本地删除 | 状态栏入口可达 |

**记录格式**：逐条记 问题（步骤/状态/键盘）→ 严重度 → 修订建议 → 是否阻断 P-015。
