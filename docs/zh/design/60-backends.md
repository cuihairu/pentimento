# 后端（Git/SVN/时光机）重启条件与未来验收（代决执行，2026-10-30）

> 状态：**已代决**。依据 `docs/review/2026-10-30-decisions.md` 执行 P-401–P-411 的立即动作。全部为**延后 V1.x** 项；本节记录重启条件、未来验收样本与能力边界，**不在 V1 实现**。

## P-401 本地 Git 仓库识别（延后，重启条件）

**重启条件**：获得实际仓库样本；只读边界获批；支持布局清单获批。未来：识别仓库与工作区状态，不修改仓库。**V1 不做**：探测外部仓库、clone、checkout、fetch、提交。

## P-402 Git 文件树与日志读取（未来验收样本）

未来按**明确提交标识**读取。验收样本：分支、删除、改名、特殊字符路径、大目录。**V1 不做**：Git 历史浏览；不只按当前路径猜历史（会把当前分支路径映射到所有提交而漏历史改名）。

## P-403 Git 历史文件提取（未来验收）

未来提取到临时/导出位置。验收：指定提交和路径**字节正确**，当前工作区前后不变。**V1 不做**：检出历史到工作区；未校验临时内容冒充原历史。

## P-404 LFS 指针与缺失对象（未来样本）

随 Git 延后，但 Git 上线时为**强制前置**。未来样本：指针、对象缺失、对象可用、非指针文本四类（区分原因，不把指针当图像解码）。**V1 不做**：指针作为图像解码；默认自动下载缺失对象。

## P-405 LFS 按需获取（延后，上线前置）

上线必须**独立同意、可取消、校验**。未来设计：下载体积、目的地、同意/拒绝、失败与哈希验证状态；优先应用缓存；明确缓存位置与实际副作用（只读仓库也可能被缓存/配置写入）。**V1 不做**：把接入 Git 当无限下载授权；后台 fetch 或修改仓库配置。

## P-406 SVN 连接（延后，重启条件）

**重启条件**：有真实 SVN 使用者与测试环境。记录需要的工作副本/URL、服务端版本、匿名与认证样本条件。**V1 不做**：收集用户凭据；把 V1 宣传为支持 SVN。

## P-407 SVN 日志树与锁（未来样本）

随连接延后。未来区分：未知/可读/无锁/有锁及权限错误（「读不到锁」≠「没有锁」）；准备锁定文件样本。**V1 不做**：获取/解除锁；把无权限当无历史。

## P-408 SVN 历史文件提取（未来验收）

未来按指定 revision 导出到库外。验收：指定 revision 内容校验，工作副本状态前后不变。**V1 不做**：提交、update 覆盖、替用户解决工作副本冲突。

## P-409 统一后端历史能力显示（能力→界面映射）

能力驱动的历史操作显示；先覆盖自建和明确未支持态。**映射**：能力 → 界面操作 → 核心校验；未来只读后端仅导出/提取（不显示写回恢复按钮）。**V1 不做**：为未实现后端显示可用标记；入口跳转当历史支持。

## P-410 macOS 时光机系统适配边界

只评估官方系统入口与权限边界，不解析备份内容。当前**保持未验证**（无 macOS 环境证据）。**V1 不做**：读取 Time Machine 快照；修改系统备份配置；承诺已备份。

## P-411 时光机能力提示与系统入口

按 P-410 验证结果处理三状态：有入口 / 无入口 / 权限失败。入口仅**已验证 macOS** 提供；其余平台说明不适用。**V1 不做**：Windows/Linux 假冒可用；缺 macOS 验证时标验收通过。
